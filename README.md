# React Registration Form – MUI, React Hook Form, Toastify, Framer Motion & Idle Timer

Реєстраційна форма, створена за допомогою **React** та **Material UI**.

У проєкті реалізовано валідацію полів форми, анімацію появи форми, індикатор завантаження, сповіщення про успішну реєстрацію та помилки, а також повідомлення при тривалій бездіяльності користувача.

## Використані технології

* **React** — створення інтерфейсу
* **Material UI (MUI)** — компоненти та стилізація форми
* **React Hook Form** — керування формою та валідація
* **React Toastify** — спливаючі повідомлення
* **Framer Motion** — анімація появи форми
* **React Idle Timer** — визначення бездіяльності користувача
* **Lucide React** — іконки полів форми
* **React Icons** — іконка кнопки реєстрації

## Реалізовано

* Реєстраційна форма з полями:

  * Name
  * Email
  * Password
* Валідація обов'язкових полів
* Перевірка мінімальної довжини імені — 2 символи
* Перевірка коректності Email
* Перевірка мінімальної довжини пароля — 8 символів
* Відображення повідомлень про помилки під відповідними полями
* Повідомлення про помилку при спробі відправити некоректну форму
* Індикатор завантаження за допомогою `CircularProgress`
* Повідомлення про успішну реєстрацію через `Toastify`
* Попередження після 1 хвилини бездіяльності користувача
* Анімація появи форми за допомогою `Framer Motion`
* Іконки біля полів форми
* Адаптивна ширина форми з максимальною шириною 400px

## Встановлення

Клонуйте репозиторій:

```bash
git clone https://github.com/llens202/home-work-51-react-specialized-libraries
```

Перейдіть у папку проєкту:

```bash
cd <назва-проєкту>
```

Встановіть залежності:

```bash
npm install
```

Запустіть проєкт:

```bash
npm run dev
```
